# Recursos y licencias

El código del proyecto se ofrece bajo MIT, con atribución colectiva en `LICENSE`. La licencia del proyecto no sustituye las licencias de terceros.

| Recurso distribuido | Procedencia | Licencia |
| --- | --- | --- |
| Iconos genéricos SVG/PNG | Geometría original generada por `scripts/generate-public-assets.mjs` | MIT del proyecto |
| `notification.wav` | Síntesis original del mismo script, sin samples | MIT del proyecto |
| Patrick Hand | Fuente de terceros con aviso incluido | SIL OFL 1.1, `apps/web/src/assets/fonts/PatrickHand-OFL.txt` |
| Dependencias npm | Versiones e integridad fijadas en `package-lock.json` | Declaraciones por paquete en `DEPENDENCY_LICENSES.json` |
| Paletas CSS | Adaptaciones con fuentes originales indicadas en `THEMES.md` | No se incluye artwork ni paquetes originales de temas |

Se excluyeron fotos de perfiles, ilustraciones personalizadas, captura de referencia y catálogos de stickers sin permiso de redistribución. El sonido anterior fue sustituido por síntesis original. No se incluyen secretos, dumps, journal activo ni datos de una conversación.

El inventario de dependencias refleja metadata de npm, no una autorización adicional ni una auditoría legal de binarios. Conserva los avisos de cada dependencia cuando distribuyas bundles o módulos; Sharp/libvips, FFmpeg, PostgreSQL, Node y Caddy tienen componentes y licencias propias que deben revisarse si se redistribuyen binarios. Esta entrega es código fuente, no una nueva distribución de sus binarios.
